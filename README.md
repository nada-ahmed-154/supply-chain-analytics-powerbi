---

## 🎯 Project Scope & Analytical Pillars
The dashboard provides comprehensive visibility across six core supply chain domains:
* **Sales & Profitability:** Tracking revenue trends, margins, and top-performing products.
* **Supplier Performance:** Evaluating supplier reliability, lead times, and cost efficiency.
* **Manufacturing Operations:** Monitoring production output, defect rates, and operational efficiency.
* **Inventory Management:** Analyzing stock levels, turnover, and holding costs.
* **Customer Analysis:** Understanding demand patterns and customer segments.
* **Shipping Performance:** Measuring delivery times, carrier performance, and logistics costs.

---

## 🔍 Methodology & Key Steps
1. **Data Cleaning & Transformation:** Processed and shaped raw datasets using **Power Query** to ensure data accuracy and consistency.
2. **Data Modeling & KPI Development:** Structured relationships and defined core business KPIs across all supply chain functions.
3. **DAX Measures:** Created custom **DAX** calculations for dynamic performance tracking and comparative analysis.
4. **Interactive Visualizations:** Built user-friendly dashboard views with dynamic filters and slicers.
5. **Report Page Tooltips:** Implemented custom tooltips to surface deeper granular insights without cluttering the main report pages.

---

## 🛠️ Tech Stack
* **BI & Visualization:** Microsoft Power BI
* **ETL & Data Prep:** Power Query
* **Calculations & Modeling:** DAX (Data Analysis Expressions)

## 🚀 How to View
1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop**.
3. Use the interactive slicers and hover over visuals to explore the custom Report Page Tooltips.
